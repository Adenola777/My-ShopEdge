# Screenshots for the TikTok Shop Go Live review, 11 October 2026

TikTok rejected "My ShopEdge" on 10 October 2026 because its screenshots contained "many small
elements or a lot of text". These six replace them. Each was taken from the production build of
the web app after the A37 redesign, at a 1100 by 690 window and twice the pixel density, so each
file is 2200 by 1380. The figures are the sample shop's, renamed "My TikTok Shop" on the local
copy, so no screen says demo or sample data.

1. `1-connect.png`: connecting a TikTok Shop through TikTok's own approval page.
2. `2-overview.png`: the Overview, with gross profit after returns and its margin.
3. `3-where-the-money-went.png`: the calculation, each TikTok fee on its own line.
4. `4-records-behind-a-line.png`: a line opened to the orders behind it.
5. `5-payouts.png`: payouts with their statement, difference and status.
6. `6-returns.png`: checking a return.

**Unverified:** TikTok's required size or format for these screenshots. The rejection email does
not state one, and the Partner Center page was not readable from the session.
